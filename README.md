# Лендинг школы логотерапии

Обновленная версия собрана как более зрелая продакшн-основа: с улучшенной семантикой, SEO, доступностью, мобильной навигацией, валидацией формы и более строгой визуальной системой.

## Что изменено

- `index.html`:
  добавлены SEO-метаданные, Open Graph, JSON-LD, skip-link, мобильная навигация, более четкая продуктовая структура и усиленные trust-блоки.
- `styles.css`:
  переработана визуальная система, добавлены дизайн-токены, состояния элементов, responsive-поведение, reduced-motion и более аккуратные сетки.
- `script.js`:
  добавлены мобильное меню, активные состояния навигации по секциям, валидация формы и аккуратная работа с анимациями.

## Почему это больше похоже на production

- Страница теперь учитывает `accessibility`:
  skip-link, `aria`-атрибуты, `aria-live`, focus states, reduced motion.
- Страница лучше подготовлена к `marketing/SEO`:
  `description`, `keywords`, `theme-color`, Open Graph и JSON-LD.
- Интерфейс ведет себя устойчивее на `mobile`:
  отдельный toggle для навигации и управляемое мобильное меню.
- Форма выглядит как реальный продуктовый блок:
  есть валидация, статусы ошибок и место для интеграции с backend или CRM.

## Технологии

- `HTML5`:
  семантическая разметка и основа для SEO.
- `CSS3`:
  дизайн-токены, адаптив, визуальные состояния, layered backgrounds.
- `Vanilla JavaScript`:
  интерактивность без лишнего runtime и без зависимости от фреймворков.

## Запуск через Vite

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

`Vite` используется как легкий dev/build-слой для статического лендинга без фреймворка.
